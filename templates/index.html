Bienvenue sur sklbz-ng

Accueil | Articles | Health

Serveur Go avec GORM et SQLite

Ce serveur permet de gérer des articles dynamiquement et de servir des fichiers statiques.

Fonctionnalités

  • ✅ Gestion d'articles via API REST
  • ✅ Stockage dans une base de données SQLite avec GORM
  • ✅ Service de fichiers statiques (JS, CSS)
  • ✅ Filtrage des articles par auteur, catégorie, tag
  • ✅ Rendu HTML des articles

API Endpoints

Méthode Endpoint Description
GET /api/articles Lister tous les articles (JSON)
POST /api/articles Créer un nouvel article
GET /api/articles/{id} Récupérer un article (JSON)
PUT /api/articles/{id} Mettre à jour un article
DELETE /api/articles/{id} Supprimer un article
GET /articles Lister tous les articles (HTML)
GET /articles/{id} Afficher un article (HTML)

Test rapide

Essayez de créer un article :

curl -X POST http://localhost:8080/api/articles \
  -H "Content-Type: application/json" \
  -d '{"title": "Test", "content": "Contenu test", "author": "Test"}'
